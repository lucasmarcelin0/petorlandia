# Instruções para agentes automáticos

**Jules (Bolt, Palette, Sentinel):** antes de qualquer sessão, leia `.jules/protocol.md`. Ele é o protocolo obrigatório deste repositório: as regras por persona, o que não propor de novo, como um PR deve ser e onde está o trabalho de maior valor. Os diários ficam em `.jules/`, em minúsculas: `bolt.md`, `palette.md` e `sentinel.md`.

Este arquivo não traz instruções para outros agentes.
